\chapter*{Preface}

This tiny document is a regression fixture for the unified builder core. It is
deliberately self-contained: it references nothing outside itself, so a clean
\code{make all} should always finish green. If a change to the core breaks a
format, building this fixture is the fastest way to see it.

It exercises the \emph{manual} genre: callouts, inline and block code, a fitted
table, and a cover image on the title page.
