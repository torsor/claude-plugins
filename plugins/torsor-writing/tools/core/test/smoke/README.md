# Core smoke test

A self-contained regression fixture for the unified builder core. It uses the
`manual` genre and exercises callouts, breakable inline code, a block listing, a
fitted table, and a cover image — with **no references to anything outside itself**,
so a clean build should always finish green.

Only the source is committed (`build.yaml`, `latex/chapters/*.tex`,
`latex/assets/cover.png`). Everything else is generated by the core.

## Run it

Build in a scratch copy so this directory stays source-only:

```bash
CORE=$(git rev-parse --show-toplevel)/plugins/torsor-writing/tools/core
tmp=$(mktemp -d)
cp -r "$CORE/test/smoke/." "$tmp/"
python3 "$CORE/assemble.py" "$tmp/build.yaml" "$tmp" --in-place
( cd "$tmp" && make all )
```

Expected tail: `PASS: all mechanical checks clean` — a fresh PDF plus HTML, both
EPUBs' non-math case, and Markdown, with no undefined refs, no overfull hboxes,
and no stray math spans.
